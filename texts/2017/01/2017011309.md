**Artikel 1.** De referentiemodellen voor de erkenning van de competenties betreffende het beroep van Metselaar-Metselaarster worden als volgt bekrachtigd:

_Table:_

| Beroep  | Kwalificaties  | Code  |
| --- | --- | --- |
| Metselaar/Metselaarster  | CE1: Systemen voor riolering en voor perifere drainage plaatsen  | MET-1 |
|  | CE3: Thermische isolatie op een bestaande muur plaatsen  | MET-3 |
|  | CE4: Gelijmd metselwerk uitvoeren  | MET-4 |
|  | CE6: Metsen met betonblokken en het plaatsen van potten/balken  | MET-6 |
|  | CE7: Parementmetselwerk met mortel uitvoeren  | MET-7  |




**Art. 2.** Dit besluit treedt op 6 december 2016 in werking.
