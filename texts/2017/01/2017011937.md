**Artikel 1.** De referentiesystemen voor de erkenning van competenties betreffende het beroep van Schilder-decorateur worden als volgt goedgekeurd :

_Table:_

| Beroep  | Kwalificaties  | Code  |
| --- | --- | --- |
| Schilder-decorateur  | CE1: Manueel schilderwerken uitvoeren op verschillende ondergronden  | PEINTDEC -1 |
|  | CE2: Met een pistool schilderwerken uitvoeren  | PEINTDEC -2 |
|  | CE3: Soepele muurbekleding aanbrengen  | PEINTDEC -3 |
|  | CE4: Soepele vloerbekleding vastkleven  | PEINTDEC -4  |




**Art. 2.** Dit besluit treedt in werking op 27 april 2017.

Het lid van het College bevoegd voor Beroepsopleiding wordt belast met de uitvoering van dit besluit.
