**Artikel 1.** De bij dit besluit gevoegde Technische Code betreffende het veiligheidsbeheersysteem van installaties voor het vervoer door middel van leidingen, wordt goedgekeurd.

**Art. 2.** Dit besluit treedt in werking op 1 juli 2017.

### Bijlage.

**Art. N.** Technische Code betreffende het veiligheidsbeheersysteem van installaties voor het vervoer door middel van leidingen.

(Beeld niet opgenomen om technische redenen, zie B.St. van 16-06-2017, p. 65470)
