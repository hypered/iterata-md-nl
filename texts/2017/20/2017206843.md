**Artikel 1.** Enig artikel. Vanaf 1 januari 2018 wordt de analyse van de volgende stoffen verplicht voor de controles m.b.t. de grondwatermonitoring vereist voor de waterproducenten overeenkomstig artikel R.43bis van en bijlage XI bij het reglementeer deel van Boek II van het Milieuwetboek, dat het Waterwetboek inhoudt :

- Code ESO 4618, desphenyl-chlooridazon, alias MET-B;

- Code ESO 4497, chloorothalonil SA, alias VIS-01;

- Code ESO 4499, metazachloor ESA ESA, alias BH479-8;

- Code ESO 4620, metolachloor ESA, alias CGA354743.
