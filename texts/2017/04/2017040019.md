**Artikel 1.** De kredieten, ingeschreven onder de begrotingsartikelen van de algemene uitgavenbegroting van de Vlaamse Gemeenschap voor het begrotingsjaar 2016, worden herverdeeld overeenkomstig de onderstaande tabel:

(in duizend EUR)

| begrotingsartikel  | basisallocatie  | KS  | van  | .. | naar | .. |
| --- | --- | --- | --- | --- | --- | --- |
|  |  |  | VAK  | VEK  | VAK  | VEK |
| CB0-1CBX2AD-PR  | CB0 CB029 0100  | VAK  | 59.500  |  |  |  |
| MB0-1MIF2AH-WT  | MB0 MI000 5421  | VAK  |  |  | 59.500  |  |
| totaal  | .. | .. | 59.500  |  | 59.500  |  |




Herverdelingsregels tussen kredietsoorten:

(1) VEK = correlatief krediet (VAK/VEK);

(2) VAK = MAC.

**Art. 2.** Een afschrift van dit besluit wordt ter kennisgeving toegestuurd aan het Vlaams Parlement, het Rekenhof en het Departement Financiën en Begroting.

**Art. 3.** De Vlaamse minister, bevoegd voor het mobiliteitsbeleid, de openbare werken en het vervoer, is belast met de uitvoering van dit besluit.
