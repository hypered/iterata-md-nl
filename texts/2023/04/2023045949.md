**Artikel 1.** De volgende referentiekaders voor de validering van competenties zijn goedgekeurd:

_Table:_

| Beroep  | Titel  | Code  |
| --- | --- | --- |
| Betontimmerman/-vrouw  | CE1: Een traditionele bekisting uitvoeren  | COFF1  |
|  | CE2: Een modulaire bekisting uitvoeren  | COFF2  |
|  | CE3: Geprefabriceerde elementen installeren  | COFF3  |
|  | CE4: Eenvoudige armaturen assembleren en installeren  | COFF4  |
|  | CE5: Een trapbekisting uitvoeren  | COFF5  |




**Art. 2.** Dit besluit treedt in werking op de dag van haar ondertekening.

### Bijlage.

**Art. N.**

(Beeld niet opgenomen om technische redenen, zie B.St. van 26-10-2023, p. 100263)
