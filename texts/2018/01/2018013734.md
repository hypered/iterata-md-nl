**Artikel 1.** Bij de zelfcontrole van zeefzand gelden voor de uitloogbaarheid de volgende normwaarden:

_Table:_

| Metaal  | Uitloogbaarheid (1)in mg/kg ds |
| --- | --- |
| As  | 0,2 |
| Cd  | 0,015 |
| Cr  | 0,5 |
| Cu  | 0,5 |
| Hg  | 0,033 |
| Ni  | 0,75 |
| Pb  | 0,4 |
| Zn  | 0,7 |




(1) Uitloogbaarheid wordt gemeten met de schudproef CMA/2/II/A.19.

**Art. 2.** Dit besluit treedt in werking op de dag van de bekendmaking ervan in het Belgisch Staatsblad.
