**Artikel 1.** De kredieten, ingeschreven onder de begrotingsartikelen van de algemene uitgavenbegroting van de Vlaamse Gemeenschap voor het begrotingsjaar 2014, worden herverdeeld overeenkomstig de onderstaande tabel :

(in duizend EUR)

| Begrotingsartikel  | Basisallocatie  | Kredietsoort  | van  | .. | naar | .. |
| --- | --- | --- | --- | --- | --- | --- |
|  |  |  | VAK  | VEK  | VAK  | VEK |
| CB0/1CA-G-2-Z/LO  | CB0 CA00000 1100  | VAK  | 232  | 232  |  |  |
| BC0/1BA-C-2-Z/LO  | BC0 BA20300 1100  | VEK  |  |  | 156  | 156 |
| CB0/1CA-G-2-Z/WT  | CB0 CA00200 1211  | VAK  | 34  | 34  |  |  |
| BC0/1BA-C-2-Z/WT  | BC0 BA22000 1211  | VEK  |  |  | 110  | 110  |
|    Totaal  | .. | .. | 266  | 266  | 266  | 266 |




Herverdelingsregels tussen kredietsoorten :

(1) VEK = correlatief krediet (VAK/VEK);

(2) VAK = MAC.

**Art. 2.** Een afschrift van dit besluit wordt ter kennisgeving toegestuurd aan het Vlaams Parlement, het Rekenhof en het Departement Financiën en Begroting.

**Art. 3.** De Vlaamse minister, bevoegd voor Financiën en Begroting, is belast met de uitvoering van dit besluit.
