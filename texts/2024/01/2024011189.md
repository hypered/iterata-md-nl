**Artikel 1.** De referentiesystemen voor de erkenning van competenties in verband met het beroep van "Huishoudhulp dienstencheques" worden goedgekeurd als volgt:

_Table:_

| Beroep  | Titel  | Code  |
| --- | --- | --- |
| Huishoudhulp dienstencheques  | UC1: De woning onderhouden  | AIMTS1  |
|  | UC2: Zorgen voor de was  | AIMTS2  |
|  | UC3: De huishoudelijke boodschappen doen  | AIMTS3  |
|  | UC4: Het voedsel klaarmaken  | AIMTS4  |




**Art. 2.** Dit besluit treedt in werking de dag waarop het wordt ondertekend.
