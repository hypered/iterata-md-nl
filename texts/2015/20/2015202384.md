**Artikel 1.** Het aantal gerechtsdeurwaarders wordt, per gerechtelijk arrondissement, bepaald als volgt :

_Table:_

| Gerechtelijk arrondissement | Aantal |
| --- | --- |
| Antwerpen | 80 |
| Limburg | 29 |
| Brussel | 87 |
| Leuven | 17 |
| Waals-Brabant | 14 |
| Oost-Vlaanderen | 58 |
| West-Vlaanderen | 49 |
| Eupen | 2 |
| Luik | 62 |
| Luxemburg | 17 |
| Namen | 28 |
| Henegouwen | 66 |




**Art. 2.** Het koninklijk besluit van 26 april 2009 tot bepaling van het aantal gerechtsdeurwaarders per gerechtelijk arrondissement wordt opgeheven.

**Art. 3.** De minister bevoegd voor Justitie is belast met de uitvoering van dit besluit.
