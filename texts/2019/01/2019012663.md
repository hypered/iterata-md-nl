**Artikel 1.** De kredieten opgenomen in begrotingsartikel FB0-1FGE5BA-IS van de algemene uitgavenbegroting van de Vlaamse Gemeenschap voor het begrotingsjaar 2019, worden herverdeeld in overeenstemming met onderstaande tabel:

(in duizend EUR)

_Table:_

| Begrotingsartikel  | Basisallocatie  | KS  | van  | .. | naar | .. |
| --- | --- | --- | --- | --- | --- | --- |
|  |  |  | VAK  | VEK  | VAK  | VEK |
| FB0-1FGE5BA-IS  | FB0 0FG007 9999  | MAC  | 350  |  |  |  |
| FB0-1FGE5BA-IS  | FB0 1FG021 6142  | correlatief krediet  |  | 350  |  |  |
| HB0-1HDI2GB-WT  | HB0 1HD144 3300  | VAK/VEK  |  |  | 350  | 350  |
| TOTAAL  | .. | .. | 350  | 350  | 350  | 350 |




Herverdelingsregels tussen kredietsoorten:

(1) VEK = correlatief krediet (VAK/VEK);

(2) VAK = MAC.

**Art. 2.** Een afschrift van dit besluit wordt ter kennisgeving toegestuurd aan het Vlaams Parlement, het Rekenhof en het Departement Financiën en Begroting.

**Art. 3.** De Vlaamse minister, bevoegd voor onderwijs, is belast met de uitvoering van dit besluit.
