**Artikel 1.** In de bijlage IIIbis van het KB/WIB 92, ingevoegd bij het koninklijk besluit van 22 augustus 2006, vervangen bij het koninklijk besluit van 31 juli 2009 en gewijzigd bij de koninklijke besluiten van 21 februari 2014, 28 april 2015, 23 augustus 2015, 19 juli 2018 en 13 april 2019, worden de volgende wijzigingen aangebracht:

1. de code "44 overuren (Art. 2751, 4de lid, 2e streepje, WIB 92)" wordt vervangen door de code "44 overuren (art. 2751, vierde lid, tweede streepje, en zevende lid, WIB 92)";

2. de code "45 overuren (Art. 2751, 4de lid, 1e streepje, WIB 92)" wordt vervangen door de code "44 overuren (art. 2751, vierde lid, eerste streepje, en zevende lid, WIB 92)";

3. de code "51 overuren (art. 2751, 4de lid, 2de streepje, en art. 2751, 7de lid, WIB 92)" wordt vervangen door de code "51 overuren (art. 2751, vierde lid, tweede streepje, en achtste lid, WIB 92)";

4. de code "52 overuren (art. 2751, 4de lid, 1ste streepje, en art. 2751, 7de lid, WIB 92)" wordt vervangen door de code "52 overuren (art. 2751, vierde lid, eerste streepje, en achtste lid, WIB 92)";

5. de code "55 horeca (Art. 2751, 4de lid, 2de streepje, en 8ste lid, WIB 92)" wordt vervangen door de code "55 horeca (art. 2751, vierde lid, tweede streepje, en negende lid, WIB 92)".

**Art. 2.** Dit besluit heeft uitwerking op de vanaf 1 januari 2019 betaalde of toegekende bezoldigingen.

**Art. 3.** De minister bevoegd voor Financiën is belast met de uitvoering van dit besluit.
