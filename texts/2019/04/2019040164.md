**Artikel 1.** De kredieten, ingeschreven onder begrotingsartikel MB0-1MHX2OB-PR van de algemene uitgavenbegroting van de Vlaamse Gemeenschap voor het begrotingsjaar 2019, worden herverdeeld overeenkomstig de onderstaande tabel:

| MB0-1MHF5RY-PA  | 0MH003 8111  | MAC  |  |  | 78.000  |  |

| MB0-1MIF5VY-IS  | 0MI016 9999  | MAC  |  |  | 7.000  |  |
| MB0-1MIF5VY-IS  | 1MI015 6141  | CORR  |  |  |  | 5.000  |
| totaal  | .. | .. | 88.780  | 8.780  | 88.780  | 8.780 |




Herverdelingsregels tussen kredietsoorten:

(1) VEK = correlatief krediet (VAK/VEK);

(2) VAK = MAC.

**Art. 2.** Een afschrift van dit besluit wordt ter kennisgeving toegestuurd aan het Vlaams Parlement, het Rekenhof en het Departement Financiën en Begroting.

**Art. 3.** De Vlaamse minister, bevoegd voor Mobiliteit en Openbare Werken, is belast met de uitvoering van dit besluit.
