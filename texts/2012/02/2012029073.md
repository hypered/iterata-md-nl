**Artikel 1.** De lestijden die jaarlijks besteed moeten worden aan opleidingen voor alfabetisering, in het Frans als vreemde taal en die toegang verlenen tot het basisstudiegetuigschrift worden op 20 000 B-lestijden vastgelegd genomen op de dotatie van het Onderwijs voor sociale promotie voor het kalenderjaar 2012.

**Art. 2.** De criteria en de nadere regels voor de toekenning van lestijden in de onderwijsinrichtingen voor sociale promotie worden als volgt bepaald :

1. 3 200 lestijden zullen voor de opleiding in gevangeniskringen bestemd worden;

2. voor het overblijvende deel van 16 800 B-lestijden kunnen de inrichtingen aanvragen om alfabetisering indienen, Frans vreemde talen en/of basisstudiegetuigschrift.

**Art. 3.** § 1. De lijst van de in aanmerking komende opleidingseenheden, met inbegrip van hun prioriteitorde, is de volgende :

1. alfabetisering :

- niveau 1 code 031001U11D1

- niveau 2 code 031002U11D1

- niveau 3 code 031003U11D1

- niveau 4 code 031004U11D1

2. Frans vreemde talen - beginner 730601U11D1.

3. Frans vreemde talen - beginner 730602U11D1.

4. Basisstudiegetuigschrift (CEB) 041503S10D1.

§ 2. De opleidingseenheid " Inleiding tot de mondelinge Franse taal voor niet-Franstaligen " code 730678U11E1 komt in aanmerking in het kader van de inrichting van opleidingen in gevangeniskringen.

**Art. 4.** Dit besluit heeft uitwerking met ingang van 1 januari 2012.

Brussel, 22 december 2011.
