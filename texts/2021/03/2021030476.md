**Artikel 1.** Het referentiesysteem voor de erkenning van competenties in verband met het beroep van " operator inzake acrobatisch hoogteparcours " wordt als volgt goedgekeurd:

_Table:_

| Beroep  | Bevoegdheid  | Code  |
| --- | --- | --- |
| Operator inzake acrobatisch hoogteparcours  | UC1: Verwelkoming en toerusting van deelnemers  | OPAH1  |
|  | UC2: Begeleiding van een acrobatische activiteit op hoogte  | OPAH2  |
|  | UC3: Evacuatie van een deelnemer aan een activiteit op een vaste structuur  | OPAH3  |
|  | UC4: Evacuatie van een deelnemer aan een activiteit op een mobiele structuur  | OPAH4  |




**Art. 2.** Dit besluit treedt in werking de dag waarop het wordt ondertekend.
