**Artikel 1.** In de bijlage van het ministerieel besluit van 23 maart 2005 tot vaststelling van de tarieven voor prestaties geleverd door de Koninklijke Bibliotheek van België, laatstelijk gewijzigd bij het ministerieel besluit van 31 augustus 2015, wordt het rubriek D vervangen als volgt:

_Table:_

| D. Toegangsprijs voor de Librije van de Hertogen van Bourgondië (KBR Museum) |  |
| --- | --- |
| Toegangsprijs | EUR |
| 1. Volle prijs (per persoon) | 11,00 |
| 2. Verlaagde prijs | 8,00 |
| - Groep (vanaf 15 personen) | 8,00 |
| - Volwassenen vanaf 65 jaar | 8,00 |
| - Studenten met geldige studentenkaart | 8,00 |
| 3. Gratis | 0,00 |
| - Kinderen en jongeren tot en met 18 jaar | 0,00 |
| - Persoon met een beperking (maximum 1 begeleider per persoon met een beperking) | 0,00 |
| - Onderwijzend personeel | 0,00 |
| - BELSPO-kaart | 0,00 |
| - Pers (met geldige perskaart) | 0,00 |




**Art. 2.** Dit besluit heeft uitwerking met ingang van 18 september 2020.
