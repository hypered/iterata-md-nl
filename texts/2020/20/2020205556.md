**Artikel 1.** De volgende referentiesystemen voor de validering van de vaardigheden worden goedgekeurd door de Waalse Regering:

_Table:_

| Beroep  | Titels  | Code  |
| --- | --- | --- |
| Monteur sanitaire verwarming (m/v)  | UC1 : de montage van een installatie van starre elementen uitvoeren via een insteekproces  | MONTCHAUFSANI-1 |
|  | UC2 : het bewerken en plaatsen van metalen-, kunststof- en draadstalenleidingen uitvoeren  | MONTCHAUFSANI-2  |
|  | UC3 : de installatie en aansluiting van verwarmingsapparatuur uitvoeren  | MONTCHAUFSANI-3  |
|  | UC4 : de bewerking en installatie van rioolbuizen, de installatie en aansluiting van sanitaire voorzieningen uitvoeren  | MONTCHAUFSANI-4  |
| Brood- en banketbakker (m/v)  | UC1 : bakkerijproducten maken  | Boulpat-1 |
|  | UC2 : banketbakkerijproducten maken  | Boulpat-2  |
| Magazijnier (m/v)  | UC1 : het ontvangen, opslaan, voorbereiden en verzenden van bestellingen  | MAGA-1  |
| Industriële schilder (m/v)  | UC1 : de manuele behandeling van een oppervlakte uitvoeren  | PEINT INDU-1  |
|  | UC2 : de behandeling van een oppervlakte door middel van hogedrukspuiten uitvoeren  | PEINT INDU-2  |
|  | UC3 : het voorbereiden van een oppervlakte door middel van abrasive blasting  | PEINT INDU-3  |
|  | UC4 : het voorbereiden van een oppervlakte door middel van metallisatie  | PEINT INDU-4  |
|  | UC5 : het voorbereiden van een oppervlakte door middel van pneumatisch spuiten  | PEINT INDU-5  |
|  | UC6 : het voorbereiden van een oppervlakte door middel van poederlakken  | PEINT INDU-6  |
| Onderhoudstuinier (m/v)  | UC : de uitvoering van voorbereidingswerkzaamheden, het onderhoud van het grasmat, de beplanting van de landschapsoppervlakken, de controle van de vegetatie en de toepassing van de geïntegreerde gewasbescherming  | JARDIENT  |
| Fonteinier (m/v)  | UC1 : de montage en installatie van pijpleidingen in een sleuf  | FONTAIN1  |
|  | UC2 : de montage en installatie van een aansluiting bij de eindklant  | FONTAIN2   |
| Uitsnijder/uitbener (m/v)  | UC1 : het uitsnijden en uitbenen van runderen of paarden  | DECDES-1  |
|  | UC2 : het uitsnijden en uitbenen van varkens  | DECDES-2  |
|  | UC3 : het uitsnijden en uitbenen van schapen of geiten  | DECDES-3  |
|  | UC4 : het uitsnijden en uitbenen van wild en pluimvee  | DECDES-4   |
| Koelmonteur (m/v)  | UC1 : de montage en aansluiting van leidingen en de bijbehorende koelcomponenten door middel van solderen of van mechanische koppelingen  | MONTFRIG-1  |
|  | UC2 : het installeren van de elektrische leidingen, het verbinden van de elektrische delen van de componenten alsook de circuits op het elektrisch paneel  | MONTFRIG-2   |




**Art. 2.** Dit besluit treedt in werking de dag waarop het ondertekend wordt.

**Art. 3.** De Minister van Werk en Vorming is belast met de uitvoering van dit besluit.
